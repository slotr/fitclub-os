02

Security

The four primitives that matter when something goes wrong.

Postgres + RLS

Multi-tenant isolation enforced at the database level on every read. Bypass requires explicit service-role keys, audited.

Stripe-only PCI scope

Card data never touches our servers. We tokenise via Stripe Elements; we store identifiers only. PCI scope is SAQ-A.

Encrypted at rest

pgcrypto on sensitive columns: qr_secret, contact PII, audit log payloads. Disk-level AES-256 underneath.

Daily backups + 30d PITR

Point-in-time recovery on Supabase Pro. Off-region encrypted backups daily, retained 30 days. Restore drill quarterly.
